Postern is a self-hosted personal context gateway: one MCP surface over the
sectors of a person's life — finance, mail, calendar, contacts, health, home —
with per-agent default-deny grants, a log of every agent request, and actions
where the source allows. It runs on your own hardware; agents connect to your
machine, not to a Postern cloud. There is no Postern service in the middle,
because there is not one. AGPL-3.0.

## The short version

Three commands on a machine you control. Docker is the only thing you install by
hand.

```bash
git clone https://github.com/getpostern/postern.git && cd postern
printf 'POSTGRES_PASSWORD=%s\n' "$(openssl rand -hex 24)" > .env
docker compose up -d
```

The gateway, its database and the Console come up together, with every published
port bound to loopback. [Install Postern](/start/install) is the same three
commands with the four facts that decide whether they hold: why the password can
never change afterwards, what `docker compose down -v` destroys, and how to reach
the Console when Postern runs on a machine you are not sitting at.

## Connect a source

Nine sources, each its own page, and none of them required. A sector answers
with whatever you have connected in it, and grants do not change when a source
does.

- **Finance** — [SimpleFIN](/connect/simplefin), the default; [Plaid](/connect/plaid) for the banks it cannot reach
- **Health** — [Apple Health](/connect/apple-health), pushed from your iPhone; [WHOOP](/connect/whoop)
- **Mail, calendar and contacts** — [Google and Gmail](/connect/google), [Microsoft](/connect/microsoft), [iCloud](/connect/icloud)
- **Home** — [Home Assistant](/connect/home-assistant), the one source an agent can act on
- **Hosted agents** — [ChatGPT](/connect/chatgpt), which needs a public address before it can reach you
