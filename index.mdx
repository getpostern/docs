Postern is a self-hosted personal context gateway: one MCP surface over the
sectors of a person's life — finance, mail, calendar, contacts, health, home —
with per-agent default-deny grants, an append-only audit ledger, and actions
where the source allows. It runs on the owner's hardware; agents connect to the
owner's gate, not to a Postern cloud. AGPL-3.0.

## Bring one up

```bash
git clone https://github.com/getpostern/postern.git && cd postern
echo "POSTGRES_PASSWORD=$(openssl rand -hex 24)" > .env
docker compose up -d
```

The gate, its database, and the Console come up together.
